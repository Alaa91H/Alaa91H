## 👨‍💻 About Me

I'm **Alaa**, an open-source developer focused on **Android**, **AOSP**, automation, privacy-first utilities, system-level tooling, and practical applications built to solve real problems.

My current work ranges from advanced Android automation and custom-ROM components to language learning, Islamic applications, download tooling, native game ports, and always-on broadcasting systems.

I care about projects that are **useful, transparent, maintainable, privacy-conscious, and technically solid**.

### 🔭 Current Focus

| Area | What I'm building |
| --- | --- |
| 📱 **Android & AOSP** | Native Android apps, Jetpack Compose interfaces, AOSP framework/system components, ROM integrations and rooted-device tooling |
| ⚡ **Automation & Utilities** | Context-aware automation, device controls, privacy tools, call management and system utilities |
| 🧠 **Learning & Daily-use Apps** | Offline-first learning experiences, sensor tools and feature-rich companion applications |
| 🛠️ **Systems & Tooling** | Rust/Tauri desktop software, FFmpeg broadcasting, Python services, CI/CD and cross-platform engineering |
